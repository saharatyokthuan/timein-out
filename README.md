# ⏱️ ลงเวลาทำงาน (timein-out)

เว็บแอปลงเวลาเข้า-ออกงานตามกะ คำนวณสาย/ออกก่อนเวลา/ขาดงาน/OT อัตโนมัติ ทำงานบนเบราว์เซอร์ เก็บข้อมูลในเครื่องผ่าน `localStorage`

---

## ✨ ฟีเจอร์หลัก

| ฟีเจอร์ | รายละเอียด |
|:---|:---|
| 📝 **บันทึกเวลา** | เลือกวันที่ กะ เวลาเข้า เวลาออก และหมายเหตุ พร้อมแสดงสถานะตัวอย่างทันทีก่อนบันทึก |
| 🧮 **คำนวณสถานะอัตโนมัติ** | ตรงเวลา / สาย / ออกก่อนเวลา / ขาดงาน / วันหยุด (สายเกิน 30 นาทีนับเป็นขาดงาน, ไม่ลงเวลาเข้านับเป็นขาดงานเต็มวัน) |
| 🌙 **กะข้ามเที่ยงคืน** | รองรับกะที่เวลาเลิกน้อยกว่าเวลาเริ่ม เช่น 22:00-07:00 |
| ⏰ **คำนวณ OT** | กะที่เปิด OT จะเริ่มนับ OT หลังทำงานครบ 9 ชม. และไม่นับเลยเวลาสิ้นสุด OT ที่ตั้งไว้ของกะ (ค่าเริ่มต้น 22:30) |
| 📜 **ประวัติ** | ดูรายการทั้งหมด เปิดรายละเอียด แก้ไข หรือลบรายการ (มีหน้าต่างยืนยันก่อนลบ) |
| 📈 **สรุป** | จำนวนวันตรงเวลา/สาย/ขาดงาน, นาทีสายและขาดงานสะสม, OT สะสม, สายเฉลี่ย/เดือน, เดือนที่สายมาก-น้อยสุด, รายการสาย/ขาดงานล่าสุด |
| 📊 **กราฟ** | กราฟเส้นแนวโน้มนาทีสายรายเดือน และกราฟแท่งมาทำงาน vs ขาดงานรายเดือน (วาดด้วย `<canvas>`) |
| ⚙️ **จัดการกะงาน** | เพิ่ม/เปลี่ยนชื่อ/ลบกะ กำหนดวันหยุดและกะ OT ได้ มีกะเริ่มต้น `T10`, `T13`, `OFF` |
| 💾 **Backup / Restore** | ส่งออกข้อมูลและกะเป็นไฟล์ `attendance-backup-YYYYMMDD.json` และนำเข้ากลับโดยรวมกับข้อมูลเดิม |
| 📊 **ส่งออก Excel** | เลือกช่วงวันที่แล้วส่งออกเป็น `attendance-<ช่วงวันที่>.xlsx` (ชีต "ลงเวลา") |
| 📥 **นำเข้า Excel** | นำเข้าไฟล์ `.xlsx` / `.xls` โดยอ่านคอลัมน์ วันที่, รหัสกะ, เวลาเข้า, เวลาออก, หมายเหตุ |

## 📁 โครงสร้างไฟล์

```
timein-out/
├── index.html    # โครงหน้าเว็บ 4 แท็บ (บันทึก / ประวัติ / สรุป / กะงาน) และ modal ต่าง ๆ
├── script.js     # ตรรกะทั้งหมด: คำนวณสถานะ, จัดการข้อมูล, กราฟ, backup, Excel

└── README.md     # ไฟล์นี้
```

## 🚀 วิธีใช้งาน

### ในเครื่อง
เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที — หรือรันผ่าน local server:

```bash
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000

> ต้องเชื่อมต่ออินเทอร์เน็ตอย่างน้อยครั้งแรก เพราะโหลดไลบรารี SheetJS จาก CDN (ใช้กับการส่งออก/นำเข้า Excel)

### ขั้นตอนใช้งาน
1. แท็บ **⚙️ กะงาน** — ตรวจสอบหรือเพิ่มกะที่ใช้งาน
2. แท็บ **📝 บันทึก** — เลือกวันที่ กะ ใส่เวลาเข้า-ออก แล้วกด "บันทึกวันนี้"
3. แท็บ **📜 ประวัติ** — ดู แก้ไข หรือลบรายการ
4. แท็บ **📈 สรุป** — ดูสถิติและกราฟ
5. ปุ่มมุมบนขวา — Backup, Restore, Excel (ส่งออก), นำเข้า Excel

## 🛠 เทคโนโลยี

- HTML / CSS / JavaScript (vanilla ไม่ใช้เฟรมเวิร์ก)
- `localStorage` เก็บข้อมูล (คีย์ `attendanceData_v1` และ `attendanceShifts_v1`)
- [SheetJS (xlsx) 0.18.5](https://cdnjs.cloudflare.com/ajax/libs/xlsx/0.18.5/xlsx.full.min.js) จาก cdnjs — ส่งออก/นำเข้า Excel
- Canvas API — วาดกราฟสรุป
